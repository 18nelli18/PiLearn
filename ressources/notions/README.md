# Fiches de notions

Une fiche par notion maîtrisée, écrite par l'Enseignant **après** validation de l'exercice
(jamais avant). Gabarit : `templates/template-fiche-notion.md`.

C'est ta base de connaissances personnelle. Elle a trois usages :

1. **Réviser** — les sessions `/reviser` piochent ici.
2. **Éviter les redites** — l'Enseignant lit ce dossier avant chaque leçon et s'appuie sur
   ce qui est déjà là au lieu de le réexpliquer.
3. **Retrouver** — dans six mois, quand tu auras oublié pourquoi ton code fait ça.

Nommage : `<notion-en-kebab-case>.md`.

Le champ `maitrise:` du frontmatter (`solide` / `fragile`) est tenu à jour par les sessions
de révision — une notion ratée en révision repasse à `fragile`.
